# Stock Portfolio

檢視自己台股庫存的桌面應用程式。單機、單人使用。

## 功能

- 追蹤持股的現價、市值與報酬（總報酬與今日報酬，可切換 % / 金額）
- 新增、修改、刪除持股
- 檢視模式與編輯模式分開，避免誤觸
- 點欄位標題即可排序
- 縮放 80%–200%，設定會記住

## 開始使用

### 下載與開啟

1. 在專案資料夾執行 `scripts\release.bat`，等畫面出現 `Build complete` 再繼續（需要 Node.js 22.12 以上）
2. 解壓 `dist\stock-portfolio-release.zip`
3. 雙擊解壓後的 `stock-portfolio-win_x64.exe`

### 第一次新增股票

1. 按工具列的「編輯」
2. 按「新增股票」
3. 輸入股票代號（名稱會自動帶出）、股數與平均成本，按「新增」
4. 按「完成」回到檢視模式

## 基本操作

| 想做什麼 | 怎麼做 |
|---|---|
| 進入或離開編輯模式 | 工具列「編輯」／「完成」 |
| 修改股數或平均成本 | 編輯模式下直接點該格，按 Enter 儲存、Esc 放棄 |
| 刪除持股 | 編輯模式下按該列的刪除，確認後即刪除，無法復原 |
| 排序 | 點欄位標題，再點一次反向排序 |
| 切換報酬顯示（% 或金額） | 工具列「顯示」→「單位」 |
| 隱藏或顯示成本欄 | 工具列「顯示」→「成本」 |
| 放大或縮小 | `Ctrl+=` 放大、`Ctrl+-` 縮小，或按住 `Ctrl` 滾動滾輪 |

## 看懂畫面

- 紅色代表上漲，綠色代表下跌（台股慣例）
- 價格前的 ▲ / ▼ 也表示漲跌，不只靠顏色辨認
- 盤中（09:00–13:30）約每 5 秒更新一次報價；非盤中只在啟動時抓一次
- 狀態列顯示更新時間與加權指數

## 資料與備份

| 檔案 | 位置 | 說明 |
|---|---|---|
| 持股與設定 | `%APPDATA%\stock-portfolio\portfolio.json` | 複製這個檔就是備份 |
| 股票代號清單 | `%APPDATA%\stock-portfolio\symbols.json` | 快取，刪掉會自動重建 |
| 執行紀錄 | `logs\app.log`（exe 所在資料夾） | 遇到問題時可提供給開發者 |

在檔案總管的網址列貼上 `%APPDATA%\stock-portfolio` 即可開啟資料夾。

## 限制

- 僅支援 Windows 與台股（上市、上櫃）
- Yahoo Finance 備援報價延遲約 20 分鐘
- 不含手續費、證交稅、股利、交易明細與已實現損益，也不支援美股與海外市場
