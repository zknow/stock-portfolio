# 功能規格

本檔是需求的**單一定義來源**。詞彙定義見 `docs/glossary.md`，技術決策理由見 `docs/adr/`。

## 1. 適用範圍

- 僅支援台股：上市（`tse_`）與上櫃（`otc_`）
- 僅單一投組，單一使用者，單機，無同步
- 不做下單、不做手續費與證交稅、不做股利、不做交易明細與已實現損益

## 2. 資料模型

一檔股票 = 一筆持股，**代號為唯一鍵**。

| 欄位 | 型別 | 說明 |
|---|---|---|
| `code` | string | 股票代號。唯一，不可重複新增，新增後不可修改 |
| `name` | string | 股票名稱。來自對照表；強制新增時由使用者自填 |
| `market` | `listing` \| `otc` | 上市 / 上櫃。決定報價查詢前綴 |
| `shares` | integer > 0 | 股數。單位為股，不是張 |
| `averageCost` | number > 0 | 平均單位成本（每股） |

`portfolio.json` 另存 UI 偏好：`sortKey`、`sortDirection`、`returnDisplay`，以及 `schemaVersion`。

## 3. 功能規格

### F1 檢視股票庫存

主畫面為單一表格，逐列一檔持股。

檢視模式可見欄位固定 7 欄，順序如下（編輯模式的「操作」欄見 F8）。最後兩欄依顯示模式二選一（見 F6）：

| 欄位 | 說明 |
|---|---|
| 代號 | `code` |
| 名稱 | `name` |
| 股數 | `shares`，千分位整數 |
| 平均成本 | `averageCost`，2 位小數 |
| 現價 | 現價解析結果；當日無成交時顯示 `—` |
| 總報酬 | 顯示模式為比率時是 `totalReturnRate`，金額時是 `totalReturn`（見 F6） |
| 今日報酬 | 顯示模式為比率時是 `todayReturnRate`，金額時是 `todayReturn`（見 F6） |

未持有任何股票時，顯示空狀態與「新增股票」引導（引導本身只在編輯模式可操作，見 F8）。

對齊規則：**文字欄（代號、名稱）靠左，數字欄靠右；欄頭與數值共用同一個對齊邊**（欄頭的排序指示符不佔文字寬度，不會把欄頭推離對齊邊）。「操作」欄的欄頭與按鈕都靠右。

### F2 新增股票

僅編輯模式可用。新增表單展開於表格上方。輸入代號後，系統查對照表帶出名稱與上市/上櫃，自動完成。

- 代號已存在 → 拒絕，提示改用編輯
- 對照表查無代號 → 拒絕，提示「查無此代號」，並顯示**強制新增**逃生門（自選上市/上櫃 + 自填名稱）。逃生門預設收起
- 股數必須為正整數，平均成本必須為正數
- 新增成功後立即納入輪詢清單，不需重啟；**並立即補抓一次報價**，使新列在非交易時段也馬上看得到價格。此單次補抓不是恢復輪詢，不違反 F5 的「時段外完全停止輪詢」

### F3 刪除股票

僅編輯模式可用。**不可逆，需二次確認**，確認對話框需顯示代號與名稱（以系統原生對話框呈現）。刪除後立即移出輪詢清單。

### F4 更新股票數量

僅編輯模式可用。可修改**股數**與**平均成本**。**不可修改代號**（變更代號等同刪除後重建）。

**就地編輯**：編輯模式下股數與平均成本兩格可直接點擊變成輸入框（同一次只編輯一列）。

- 提交：該列的「儲存」鈕、或輸入框內按 Enter
- 取消：該列的「取消」鈕、或輸入框內按 Esc
- 驗證沿用 F2（股數正整數、成本正數），不合法則拒絕並保留輸入內容
- **5 秒輪詢的重繪不得打斷輸入**：輸入中的內容與游標位置必須在重繪後保留

### F5 即時追蹤股票價格

| 項目 | 規則 |
|---|---|
| 主來源 | MIS 即時報價，批次請求（一個請求攜帶全部持股） |
| 輪詢間隔 | 5 秒 |
| 輪詢時段 | 台北時間 09:00–13:30，週一至週五。時段外完全停止輪詢 |
| 收盤 | 13:30 後補抓一次，確認收盤價後停止 |
| 首次載入 | 啟動後立即抓一次，若為非交易時段則抓一次即停；這次若沒取得全部持股的報價，延遲 5 秒重試一次後停止（ADR-0014） |

**現價解析順序**（實作於 `services/quote/MisProvider.ts`，必須有單元測試）：

1. `trade.z` 為有效價格 → 採用
2. 否則 `z` 為有效價格 → 採用
3. 否則視為**當日無成交**

**價格缺值判定**：`"-"`、`"—"`、空字串、非數字，以及 `0` 或負數，一律視為缺值（`null`）。價格必為正數，故 `0` 不可能是有效報價。

**壞代號判定**：MIS 對錯誤代號或錯誤前綴**不會回傳錯誤**，而是回傳佔位物件 `{"tv":"-","s":"-","c":"","z":"-"}`，插入在陣列中的原位置。判定條件為 `c === ""`，不能只看陣列長度。

**當日無成交**（`z === "-"`、`v === "0"`、無 `trade` 物件）：

- 現價欄顯示 `—`，整列淡化
- 計算用的估值價改用昨收（`y`），因此報酬率與市值仍可計算，總計不會出錯

### F6 顯示投資報酬率

單位為股。不含手續費、證交稅、股利。

```
總報酬金額   = (估值價 − 平均成本) × 股數
總報酬率     = (估值價 − 平均成本) / 平均成本
今日報酬金額 = (估值價 − 昨收) × 股數
今日報酬率   = (估值價 − 昨收) / 昨收
市值         = 估值價 × 股數
```

其中 **估值價** = 現價；當日無成交時 = 昨收；兩者皆缺時為 `null`。

**顯示模式**：兩個報酬欄以「比率」或「金額」其中之一呈現，同一時間只顯示一種，由工具列的切換鈕控制（ADR-0015）。切換鈕本身顯示當前單位（`%` 或 `NT$`）。

| 模式 | 欄頭 | 逐列數值 |
|---|---|---|
| `rate`（預設） | 總報酬率、今日報酬率 | 2 位小數 + `%`，正數加 `+` |
| `amount` | 總報酬金額、今日報酬金額 | 千分位 + 0 位小數，逐列不加 `NT$` |

模式選擇寫入 `portfolio.json`（見 F14）。

**缺值處理**：

| 缺什麼 | 結果 |
|---|---|
| 估值價為 `null` | 該列報酬欄位全顯示 `—`，**不計入總成本、總市值、總報酬與今日總報酬**；總計列旁標註被排除的檔數 |
| 估值價有值但昨收為 `null` | 總報酬與市值照算，只有今日報酬欄顯示 `—`，且不計入今日總報酬；總計列另標註此類檔數 |

### F7 設定單位成本

見 F4。平均單位成本為使用者手動輸入值，不由系統計算（不存交易明細，見 ADR-0002）。

### F8 檢視模式 / 編輯模式切換

| 模式 | 行為 |
|---|---|
| 檢視 | 唯讀。新增鈕、刪除鈕、欄位編輯全部隱藏。表格維持 7 欄。報酬顯示切換鈕仍可用 |
| 編輯 | 顯示新增鈕與每列刪除鈕；股數與平均成本可點擊就地編輯。表格另加一欄「操作」，放置該列的刪除鈕與（輸入中時的）儲存 / 取消鈕 |

- 切換入口為工具列的切換鈕，不提供鍵盤快捷鍵
- 預設為檢視模式。模式狀態不持久化，每次啟動回到檢視模式

### F9 深色模式

**固定深色**。不提供亮色主題，也不提供切換鈕。所有顏色取自 CSS 變數（design token），集中於 `src/ui/theme.css`。

**漲跌配色採台股慣例：紅漲綠跌。** 此為刻意的在地慣例，不得「修正」為國際慣例。

### F10 僅限台股

按鈕與輸入不提供美股或其他市場選項。新增股票時若代號格式不符台股（4–6 位英數字）直接拒絕。上市 / 上櫃由對照表判定。

### F11 等比縮放與視窗貼合內容

視窗可自由拖拉；**內容依視窗寬度對基準寬 1100 等比縮放**。

- 縮放因子 = 視窗寬度 / 1100，套用到字級與間距；**欄寬由內容決定**（貼齊，不隨視窗寬度拉開）
- **縮放因子下限 0.85**（對應視窗寬 935）。窄於 935 之後內容不再縮小（ADR-0016）
- **視窗尺寸由內容推得**：在縮放下限下量測內容（工具列、表格、總計列、狀態列）的自然寬度，再加上目前的垂直捲軸寬度即為視窗寬度（沒有捲軸時右緣完全貼齊）；視窗高度 = 寬度 × 760 / 1100
- **啟動時與內容變動時都貼合內容**（ADR-0016）。所有欄位都在畫面上，**不依賴水平捲動**
- 列數多到出現垂直捲軸時，寬度會多一個捲軸寬，視窗自動變寬，最右欄不被捲軸擠掉
- 內容（持股、編輯模式、報酬顯示模式）改變時重算並套用
- 新增表單不列入量測（表單可換行，不會造成水平溢出）
- 驅動方式為 DOM `window` 的 `resize` 事件（Neutralino **沒有** `windowResize` 事件），更新 CSS 自訂屬性
- **不鎖定視窗寬高比**。Neutralino 沒有原生 aspect ratio 鎖定，硬做會與使用者拖拉互搶控制權

### F12 投組總計列

表格底部固定一列，顯示總成本、總市值，以及顯示模式對應的兩個報酬項目（見 F6）：

| 顯示模式 | 報酬項目 |
|---|---|
| `rate`（預設） | 總報酬率、今日報酬率 |
| `amount` | 總報酬金額、今日報酬金額 |

總成本與總市值不隨模式切換（不是報酬指標）。金額一律前置 `NT$`。

**總報酬率 = 總報酬金額 / 總成本**，不是逐列報酬率的平均。

**今日報酬率 = 今日總報酬 / 昨日總市值**（昨日總市值 = Σ 昨收 × 股數），同樣不是逐列報酬率的平均。分母為 0（無持股，或持股全缺昨收）時顯示 `—`。

計算範圍排除估值價為 `null` 的持股，排除檔數在列旁標註。昨收為 `null` 者不計入今日總報酬，也不進今日報酬率的分母，其檔數一併標註。

### F13 排序

- 預設依**市值遞減**（市值 = 估值價 × 股數；市值不顯示但仍為排序鍵）
- 7 個顯示欄位全部可點擊欄頭切換升冪 / 降冪
- 切換顯示模式（F6）時，若當前排序鍵正好落在被隱藏的欄位，自動換成同組的另一個：`totalReturn` ↔ `totalReturnRate`、`todayReturn` ↔ `todayReturnRate`，方向不變
- 點擊尚未排序的欄位時，數字欄由大到小、文字欄由小到大；再點同一欄則反向
- **缺值一律排最後**，不受升冪或降冪影響
- 排序選擇寫入 `portfolio.json`，下次啟動還原

### F14 記憶 UI 偏好

`portfolio.json` 保存：排序鍵與方向、報酬顯示模式（F6）。啟動時還原。**視窗寬高不保存**：視窗尺寸一律由內容推得（F11、ADR-0016），使用者手動拉過的尺寸不會記住。

### F15 資料來源狀態顯示

狀態列常駐顯示：

| 情境 | 顯示 |
|---|---|
| 正常 | `更新於 HH:mm:ss` + `MIS 即時` |
| 降級 | `更新於 HH:mm:ss` + `Yahoo（延遲約 20 分）`，並使用警示色 |
| 資料非當日 | 額外標記「非當日資料」（以 MIS 回應的 `d` 欄位判斷是否為今日） |
| 非交易時段 | `已收盤` 或 `非交易時段`，不顯示輪詢中 |

### F16 日誌

`logs/app.log` 只記錄：啟動與關閉、報價抓取失敗的次數與原因（含逾時）、MIS 未回傳報價的代號（查無資料，記 WARN，不計入失敗、不降級）、非交易時段首抓失敗後的延遲重試、降級到 Yahoo 與回試 MIS 的事件、對照表更新結果。**不記錄每次成功的輪詢。**

## 4. 報價來源與降級

### 4.1 MIS 即時報價（主）

```
GET https://mis.twse.com.tw/stock/api/getStockInfo.jsp
    ?ex_ch=<ch>&json=1&delay=0
```

- `<ch>` 格式：`tse_2330.tw`（上市）、`otc_6488.tw`（上櫃），多檔以 `|` 分隔
- 附上 `Referer: https://mis.twse.com.tw/stock/index.jsp`（實測非必要，但求穩）
- 傳輸在框架層完成，繞過 webview CORS。一律經 `services/http.ts` 的 `getText(url)`，它會回傳 `{ status, body }`，`body` 為字串，需自行 `JSON.parse`。實際傳輸方式見 ADR-0009
- 回應外層含 `rtcode`、`rtmessage`、`msgArray`
- 限流：官方無規定。社群慣例為 3 次 / 5 秒，實測 25 次 / 20.6 秒未遭封鎖。**批次輪詢即為遵守此慣例的手段**
- 非官方、未公開端點。故隔離於單一 `MisProvider`，可隨時替換

MIS 實用欄位：

| 欄位 | 意義 |
|---|---|
| `c` | 代號。空字串代表此代號查無資料 |
| `n` | 名稱 |
| `ex` | `tse` / `otc` |
| `z` | 當盤成交價。`"-"` 代表當日無成交 |
| `y` | 昨收 |
| `t` | 資料時間。收盤後為 `13:30:00` |
| `d` | 資料日期，格式 `YYYYMMDD` |
| `v` | 累計成交量 |
| `trade.z` | 最後一筆成交價，比 `z` 可靠 |

實測：13:30 收盤後 API 照常回應，`z` 為收盤價、`t` 為 `13:30:00`，**API 不會在盤外停止服務**，是我們主動停止輪詢。週末與假日的回應行為無第一手驗證，故以 `d` 是否為今日作為防禦。

### 4.2 Yahoo Finance（備援）

```
GET https://query1.finance.yahoo.com/v8/finance/chart/<symbol>?interval=1d&range=1d
```

- `<symbol>`：上市為 `2330.TW`，上櫃為 `6488.TWO`
- 免金鑰。`meta.regularMarketPrice` 為現價，`meta.chartPreviousClose` 為昨收
- 延遲約 20 分鐘。降級時必須在狀態列標示
- 不使用 `/v7/finance/quote`（2023 起需 cookie 與 crumb，已不可用）

### 4.3 降級與回試

| 事件 | 行為 |
|---|---|
| MIS 連續失敗 3 次 | 降級至 Yahoo，狀態列變警示色，寫入 log |
| 降級中 | 每 5 分鐘試回 MIS 一次 |
| 試回成功 | 恢復 MIS，狀態列還原，寫入 log |

### 4.4 代號對照表

每日合併兩個官方端點，寫入 `config/symbols.json`：

| 市場 | 端點 | 約略筆數 |
|---|---|---|
| 上市 | `https://openapi.twse.com.tw/v1/exchangeReport/STOCK_DAY_ALL` | 1379（含 ETF / ETN / TDR / REIT / 特別股） |
| 上櫃 | `https://www.tpex.org.tw/openapi/v1/tpex_mainboard_quotes` | 1012（含 ETF / ETN） |

- 兩者皆免金鑰；市場別由「哪個端點回傳」推得
- **不使用** `tpex_mainboard_daily_close_quotes`（12565 筆，多數為權證，過於嘈雜）
- 更新時機：啟動時檢查 `symbols.json` 的日期，非當日才更新；更新失敗沿用舊快取
- 兩個端點僅涵蓋「當日有成交」的標的。冷門標的若缺席，以強制新增逃生門處理

## 5. 數字格式

| 項目 | 格式 |
|---|---|
| 價格、平均成本 | 千分位 + 2 位小數 |
| 股數 | 千分位整數 |
| 金額 | 千分位 + 0 位小數（`NT$` 前綴加在總計列，逐列不加） |
| 報酬率 | 2 位小數 + `%`，正數加 `+` |
| 漲跌方向 | 紅漲綠跌；無成交為中性色。**顏色不得是唯一訊號**：現價欄在數字前加 `▲` / `▼`（ADR-0007） |
| 缺值 | `—` |

## 6. 範圍外

CSV 匯入/匯出、i18n 多語、亮色主題與切換鈕、交易明細與已實現損益、股利與費稅、官方 EOD 校正層、券商 API、自動更新、多投組、跨裝置同步、下單。
