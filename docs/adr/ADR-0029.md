# ADR-0029：持股與對照表改存 `%APPDATA%\stock-portfolio\`

- 狀態：已決定
- 日期：2026-10-27

## 背景

ADR-0004 將 `portfolio.json` 與 `symbols.json` 放在應用程式目錄的 `config/`。資料與程式同目錄時，解壓新版本或重新解壓 ZIP 會影響個人資料，備份位置也不固定。

## 決策

- `portfolio.json`、`symbols.json` 存於 `%APPDATA%\stock-portfolio\`。路徑由 `os.getEnv('APPDATA')` 解析。
- 程式不再讀寫 `config/`。
- `neutralino.config.json` 的 `dataLocation` 維持 `"app"`，本專案不使用框架的資料目錄。
- `logs/app.log` 位置不變。

## 理由

- 資料與程式目錄分離，更新或重新解壓不影響資料。
- 位置固定，備份與尋找只有單一路徑。
- 沿用 ADR-0004 的 JSON 格式與 `filesystem` API，只改位置，不新增依賴。

## 後果

- ADR-0004 的「綠色可攜」理由不再成立：複製整個專案目錄到另一台機器不會帶走資料，需另外複製 `%APPDATA%\stock-portfolio\`。
- 依賴 `APPDATA` 環境變數。`load` 的讀取失敗會回到預設庫存，因此缺少該變數時應以 log 排查。
- `.gitignore` 保留 `config/` 規則，避免殘留的個人資料被納入版控。
