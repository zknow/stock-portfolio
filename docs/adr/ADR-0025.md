# ADR-0025：前置檢查合併為 prepare.bat，release 改直接呼叫本地 CLI

- 狀態：已決定
- 日期：2026-10-27

## 背景

`start.bat` 與 `release.bat` 各自重複了 `node_modules` 檢查與 `npm install`。`ensure-bin.bat` 只負責框架執行檔，名稱無法涵蓋依賴安裝。`release.bat` 以 `npx neu` 呼叫 CLI，與 `start.bat` 的直接呼叫方式不一致。

## 決策

1. **`scripts\ensure-bin.bat` 改名為 `scripts\prepare.bat`**，同時負責框架執行檔下載與 `node_modules` 檢查。流程為：`bin\` 缺檔即下載；`node_modules\` 缺目錄即執行 `npm install`。任一步失敗即回傳非零結束碼。
2. **`start.bat` 與 `release.bat` 只呼叫一次 `prepare.bat`**，不再各自檢查依賴。
3. **`release.bat` 改為 `node node_modules\@neutralinojs\neu\bin\neu.js build --release`**，與 `start.bat` 一致，不經 `npx`。

取代 ADR-0022 決策 2 的腳本名稱與職責。`.tmp\` 相關細節已由 ADR-0024 取代。

## 理由

- 前置步驟集中在一處，修改下載或安裝邏輯只需改一個檔。
- 腳本名稱反映實際職責。
- 本地 CLI 路徑統一，少一層 `npx` 行程。

## 後果

- `ensure-bin.bat` 不再存在；引用它的文件已同步改為 `prepare.bat`。
- `prepare.bat` 的失敗訊息由呼叫端負責暫停與結束，與原行為相同。
