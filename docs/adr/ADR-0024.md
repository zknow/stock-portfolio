# ADR-0024：精簡資源與下載暫存目錄

- 狀態：已決定
- 日期：2026-10-27

## 背景

`resources/icons/` 只有一張圖，多一層目錄沒有分類作用。`scripts\ensure-bin.bat` 另建 `.tmp\` 存放下載的 zip，解出後即刪除，目錄本身常態為空。

## 決策

1. **圖示移到 `resources/appIcon.png`**，`neutralino.config.json` 的 `modes.window.icon` 改為 `/build/appIcon.png`。`resources/` 只留 `appIcon.png` 與 `favicon.ico`。
2. **`ensure-bin.bat` 的下載暫存改用 `bin\`**，zip 解出執行檔後即刪除，不再建立 `.tmp\`。`.gitignore` 移除 `.tmp/`（`bin/` 已排除）。

本 ADR 取代 ADR-0010 的圖示路徑與 ADR-0022 決策 2 的 `.tmp\` 暫存路徑。

## 理由

- 少一層目錄與一個常態為空的暫存目錄，同一職責只留一個位置。
- `bin/` 本來就不進版控，暫存 zip 留在其中不會誤入版本庫。

## 後果

- 圖示路徑變更後需重新執行 `npx neu build --release` 或 `npm run build` 才會更新 `build/`。
- `ensure-bin.bat` 若下載或解壓失敗，殘留的 zip 會留在 `bin\`，需手動刪除後重跑。
