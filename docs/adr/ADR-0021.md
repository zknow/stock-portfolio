# ADR-0021：顯示設定收進工具列面板，成本與單位採左右分割選項

- 狀態：已決定
- 日期：2026-10-20

## 背景

ADR-0020 的成本欄位使用自繪 switch，單獨放在報酬顯示切換鈕左側。實際使用後，switch 的軌道與工具列其他按鈕的長方形邊框不一致，看起來像外來的控制項；報酬顯示又只有一顆顯示當前單位的文字鈕，兩個相鄰的控制項難以形成同一組設定。

把成本改成長方形左右分割選項後，`%` / `NT$` 若仍是一顆循環切換鈕，會和旁邊的分割選項格格不入。兩者都改成「名稱＋左右分割選項」時，工具列會被撐寬，標題空間不足。

## 決策

1. **成本與報酬單位收進同一個「顯示」面板**：工具列只留一顆帶下箭頭的「顯示」按鈕，展開時箭頭轉上；展開後是成本與單位兩個控制項。面板外點擊或按 Esc 關閉；切換編輯模式時也關閉。
2. **兩個控制項都是左右分割選項**：
   - 成本：`顯示` / `隱藏`，對應 `showCost` 的 `true` / `false`。
   - 單位：`%` / `NT$`，對應 `returnDisplay` 的 `rate` / `amount`。
   - 每個選項是 `button` + `aria-pressed`，外層以 `role="group"` 與 `aria-label` 標示「成本欄位」／「報酬單位」。
3. **面板尺寸固定對齊**：標籤欄 `30px × --scale`、選項欄 `86px × --scale`、欄距 `8px × --scale`；兩個選項控制項同寬，左右邊界對齊。面板寬度由內容決定，不設固定大寬度。
4. **編輯與新增改成圖示鈕**：
   - 檢視模式的編輯鈕是鉛筆 SVG；編輯模式換成勾號 SVG，代表完成。
   - 新增股票是加號 SVG，依現況只在編輯模式出現。
   - 圖示鈕為 `28 × 26px × --scale` 的方形按鈕，保留 `title` 與 `aria-label` 作為 tooltip 與無障礙名稱。
5. **行為與偏好不變**：`showCost`、`returnDisplay` 的預設值、持久化、排序鍵對映、成本隱藏時的欄位與總計規則都沿用 ADR-0020 與 F6 / F17。此 ADR 只取代 ADR-0020 決策 5 的 switch 形式。

## 理由

- 兩個控制項都是二選一，左右分割比 switch 加文字鈕更能表達「同一組設定」。
- 面板讓工具列的標題區不必和兩個完整控制項搶寬度；展開後才佔用空間。
- 固定標籤欄與選項欄寬度，讓兩列在視覺上對齊，不會因文字長度不同而左右跳動。
- 圖示鈕把「編輯」與「新增」壓縮成固定方形，讓工具列在窄視窗仍保留標題空間；`title` 與 `aria-label` 補足圖示的語意。
- 沿用現有 CSS 變數與 `--scale`，不引入新依賴或 UI 框架。

## 後果

- 切換顯示設定多一次點擊；換取工具列更安靜、標題空間更完整。
- 圖示鈕需要 tooltip 才能讓第一次使用的人確認語意；加號只在編輯模式出現，與現有行為一致。
- 面板是絕對定位的彈出層，實作需處理外點關閉、Esc 關閉與模式切換時關閉。
- 成本與單位控制項的實機驗收應涵蓋 0.85 與其他縮放倍率下的對齊。

## 曾考慮的替代方案

- **保留 switch，只把報酬單位也改成開關**：兩個開關語意不一致（成本是顯示／隱藏，單位是比率／金額），且開關仍與工具列按鈕風格不同。
- **兩個控制項都留在單列工具列**：最省高度，但標題空間被壓縮，視窗變窄時最先犧牲標題。
- **成本與單位各自一個彈出面板**：多了兩個入口，操作更分散；兩者都屬於顯示設定，應共用一個面板。
- **加號常駐在檢視模式**：可少一次點擊，但會改變「新增只在編輯模式」的既有行為；本次不動功能邏輯。
- **使用文字按鈕取代圖示**：最不需學習，但工具列較寬，且使用者明確要求測試圖示版本。
