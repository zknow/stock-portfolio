# ADR-0003：報酬率公式（未實現、不含費稅股利）

- 狀態：已決定
- 日期：2026-10-16

## 背景

需求要求顯示「總報酬 / 今日報酬」。報酬的定義有多種可能，差別在於是否納入手續費、證交稅與股利，以及今日報酬的基準是什麼。

## 決策

以**估值價**為基準，計算四個數值，**不含手續費、證交稅、股利**：

```
總報酬金額   = (估值價 − 平均單位成本) × 股數
總報酬率     = (估值價 − 平均單位成本) / 平均單位成本
今日報酬金額 = (估值價 − 昨收) × 股數
今日報酬率   = (估值價 − 昨收) / 昨收
市值         = 估值價 × 股數
```

其中 **估值價** = 現價解析結果；**當日無成交時等於昨收**。

單位為股（非張）。昨收缺失時估值價為 `null`，該列報酬顯示 `—` 且不計入總計。

## 理由

- 這組公式只需要「現價 + 昨收 + 股數 + 平均成本」四個輸入，與 ADR-0001 選定的資料來源完全對齊，不需要任何額外資料源或參數。
- 這是台股看盤軟體最常見的「未實現損益」定義，使用者一看就懂，無需在 UI 上解釋。
- 今日報酬以昨收為基準，而非「今日開盤」或「今日首次取得價」，因為昨收正是 MIS 直接提供的欄位（`y`），且是市場公認的當日漲跌基準。
- 不計手續費與證交稅：買進費率 0.1425%、賣出再加 0.3% 證交稅，費率會變動且各家券商折扣不同。納入會需要費率設定，且讓「總報酬」變成一個依賴假設的數字。
- 不計股利：需要除權息與股利發放資料源，且除權息會影響股數與成本，牽動整個模型。

## 後果

- 畫面上顯示的總報酬是**未實現損益**，不含任何已發生或將發生的成本。若使用者要與券商對帳，數字會對不上，這是預期行為。
- **估值價在「當日無成交」時退化成昨收**。這是刻意的：冷門標的當日無成交不代表沒有價值，用昨收估值可讓報酬率與市值仍可計算，總計不會出錯。但現價欄仍顯示 `—` 並淡化整列，讓使用者知道這不是真實成交價。
- 公式被 `AGENTS.md` 列為硬性約束：變更必須先新增 ADR。
- `pnl.ts` 必須是可純函式測試的核心，且在「估值價為 `null`」時必須能被總計邏輯排除。

## 曾考慮的替代方案

- **納入手續費與證交稅**：更接近實際損益，但需費率設定與買進/賣出方向的假設，且未實現狀態下賣出稅尚未發生，語意模糊。
- **納入股利**：反映真實總報酬，但需要股利資料源、除權息處理、股數與成本的調整邏輯。
- **今日報酬以今日開盤為基準**：排除前一日收盤到今日開盤的跳空，但「今日報酬」的市場慣例基準是昨收。
- **只顯示報酬率、不顯示金額**：欄位更少，但總計列的價值就在金額，且使用者常需要具體金額。
