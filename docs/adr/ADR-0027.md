# ADR-0027：Job Object 啟動程式內嵌於 start.bat

- 狀態：已決定
- 日期：2026-10-27

## 背景

ADR-0026 以獨立的 `scripts\run-app.ps1` 建立 Job Object 並執行 `neu run`。這個檔案只被 `start.bat` 呼叫一次，獨立成檔增加了維護的檔案數，卻沒有被其他地方重用。

## 決策

1. **刪除 `scripts\run-app.ps1`**，PowerShell 啟動程式移入 `scripts\start.bat`，置於 `:PSBEGIN` 標籤之後。
2. **`start.bat` 以 `-Command` 讀取自身檔案**：`iex` 執行 `:PSBEGIN` 之後的文字。`cmd` 在 `exit /b` 後不會解析標籤以下的內容。
3. **`inspector` 參數改以環境變數 `INSPECT` 傳遞**，取代 `-Inspector` 開關。

## 理由

- 單一入口，啟動流程只需讀一個檔案。
- 避免在命令列內嵌多行 PowerShell，引號與跳脫問題較少。

## 後果

- `start.bat` 內同時包含批次與 PowerShell，修改時需注意 `:PSBEGIN` 標籤之後是 PowerShell 語法。
- PowerShell 段落必須保持純 ASCII，與批次檔的既有限制一致。
- Job Object 的行為與 ADR-0026 相同，僅檔案位置改變。
