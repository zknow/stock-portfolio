# 領域詞彙表

本檔是領域詞彙的**單一定義來源**。程式碼、文件與 UI 用語一律以此為準。

## 持股與市場

| 詞彙 | 定義 |
|---|---|
| **持股** | 一筆庫存記錄。以代號為唯一鍵，一檔股票只會有一筆持股 |
| **代號** | 台股證券代號，4–6 位英數字（例：`2330`、`00878`、`020000`）。唯一，新增後不可修改 |
| **名稱** | 證券簡稱，來自對照表 |
| **上市** | 台灣證券交易所掛牌。報價前綴 `tse_`，Yahoo 後綴 `.TW` |
| **上櫃** | 證券櫃檯買賣中心掛牌。報價前綴 `otc_`，Yahoo 後綴 `.TWO` |
| **投組** | 全部持股的集合。本專案只有一個投組 |
| **對照表** | 代號 →（名稱、上市/上櫃）的本地快取。每日由官方 OpenAPI 更新 |

## 數量與成本

| 詞彙 | 定義 |
|---|---|
| **股** | 計量單位，本專案儲存的唯一單位 |
| **張** | 1 張 = 1000 股。僅為顯示單位，不儲存 |
| **股數** | 持有股數，正整數 |
| **平均單位成本** | 每股的平均取得成本。由使用者手動輸入，不由系統計算 |
| **總成本** | 平均單位成本 × 股數 |

## 價格

| 詞彙 | 定義 |
|---|---|
| **現價** | MIS 的當盤成交價。解析順序：`trade.z` → `z`。當日無成交時無現價，UI 顯示 `—` |
| **估值價** | 用於計算報酬與市值的價格。一般等於現價；**當日無成交時等於昨收**；昨收亦缺失時為空 |
| **昨收** | 前一交易日的收盤價，MIS 欄位 `y`。今日報酬的基準 |
| **收盤價** | 13:30 收盤時的成交價。收盤後 MIS 的 `z` 即為收盤價，`t` 為 `13:30:00` |
| **當日無成交** | 該證券當日完全沒有成交。MIS 的 `z` 為 `"-"`、`v` 為 `"0"`，且回應中沒有 `trade` 物件。**與「盤後」不同** |
| **漲跌** | 現價 − 昨收 |
| **漲跌幅** | (現價 − 昨收) / 昨收 |

## 報酬

| 詞彙 | 定義 |
|---|---|
| **總報酬金額** | (估值價 − 平均單位成本) × 股數。未實現 |
| **總報酬率** | (估值價 − 平均單位成本) / 平均單位成本 |
| **今日報酬金額** | (估值價 − 昨收) × 股數 |
| **今日報酬率** | (估值價 − 昨收) / 昨收 |
| **市值** | 估值價 × 股數。不顯示於表格，但作為預設排序鍵 |
| **已實現損益** | 賣出後的實際獲利。**本專案不計算** |

總報酬與今日報酬**均不含手續費、證交稅與股利**。

## 報價運作

| 詞彙 | 定義 |
|---|---|
| **MIS** | `mis.twse.com.tw` 的即時報價端點。非官方、未公開，但免金鑰且為真即時 |
| **輪詢** | 定時重複請求報價。本專案為 5 秒一次，且**批次**（一個請求攜帶全部持股） |
| **批次請求** | 以 `|` 串接多個 `ex_ch` 通道，一次取得全部持股報價 |
| **交易時段** | 台北時間週一至週五 09:00–13:30。此時段外完全停止輪詢 |
| **資料日期** | MIS 回應的 `d` 欄位，格式 `YYYYMMDD`。非今日時 UI 標記「非當日資料」 |
| **降級** | MIS 連續失敗 3 次後，改用 Yahoo Finance 作為報價來源 |
| **回試** | 降級期間每 5 分鐘試探 MIS 是否恢復 |
| **佔位物件** | MIS 對查不到的代號回傳的假資料 `{"tv":"-","s":"-","c":"","z":"-"}`，**不帶錯誤碼**。判定條件為 `c === ""` |
| **強制新增** | 對照表查無代號時的逃生門：使用者自選上市/上櫃並自填名稱 |
| **EOD** | End of Day，收盤後的當日資料。官方 OpenAPI 的 `STOCK_DAY_ALL` 與 `tpex_mainboard_quotes` 屬此類 |

## 介面

| 詞彙 | 定義 |
|---|---|
| **檢視模式** | 唯讀模式。隱藏所有編輯控制項。啟動時的預設模式 |
| **編輯模式** | 可新增、刪除、修改股數與平均單位成本的模式 |
| **投組總計列** | 表格底部的固定列，顯示總成本、總市值、總報酬金額、總報酬率、今日總報酬。其中總報酬率為總報酬金額 ÷ 總成本 |
| **紅漲綠跌** | 台股慣例：上漲顯示紅色、下跌顯示綠色。**與歐美慣例相反，此為刻意選擇** |
| **更新時間** | 最近一次成功取得報價的本地時間，顯示於狀態列 |
| **缺值** | 無法計算的數值，UI 一律顯示 `—`，並排除於總計之外 |
